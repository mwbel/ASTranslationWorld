# Batch 提交错误诊断

- 提交失败时保存脱敏 HTTP 状态码、异常说明和 upload/create_batch 阶段；上传成功后保存远端文件编号，支持复用已有上传。
- 用既有第 1 页文件创建一次 Batch，关闭 SDK 重试。Google 返回 HTTP 400 FAILED_PRECONDITION，消息为 Precondition check failed；未创建成功。
- 返回内容未说明具体前提条件，下一步需核对实际密钥所属项目的结算及 Batch 使用资格，不能据此断言余额不足。
- 其他页保持暂停，后台服务未启动。模拟测试验证一次创建、不重复上传和密钥脱敏。

前端 app：显示保存的详细错误。管理后台：无需同步。后端：继续核对项目条件。数据库：无需同步，本地识别缓存保留。
